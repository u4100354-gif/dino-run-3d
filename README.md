# Dino Run 3D
Браузерная игра на русском языке. Коротколапый тираннозавр бежит по трём трассам длиной 420, 620 и 820 метров. Стрелки влево и вправо управляют движением, пробел или ↑ запускает прыжок (удержание увеличивает высоту), ↓ позволяет пригнуться. Esc ставит игру на паузу. На сенсорном экране используйте кнопки внизу.
 
Каждый метр даёт одно очко, золотой кристалл — ещё 25. Бирюзовый щит поглощает одно столкновение. Первый и второй финиши на разных трассах открывают облики. Рекорд и облики сохраняются в локальном хранилище браузера.
 
Откройте index.html двойным щелчком или включите GitHub Pages для корня ветки main. Сборка, сетевые зависимости и серверная часть не требуются. Геометрия, анимация и звуки создаются в браузере.
